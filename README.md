# Milan Enterprises Pvt. Ltd. — Manufacturing Website + Admin Control Panel

A complete, production-ready business website for a machine manufacturing company in
**Khalikot, Ganjam, Odisha** — paper plate machines, paper cup machines, agarbatti machines,
raw materials and spare parts — with a full multilingual customer site (English / हिन्दी / ଓଡ଼ିଆ)
and a role-based admin panel.

Built with **Next.js (App Router) + TypeScript + Tailwind CSS 4 + PostgreSQL + Drizzle ORM**.
HTML/CSS/JS are all generated by the React app; a dependency-free **Python** port of the ROI
engine is included in `scripts/roi_engine.py` for offline calculations or an optional Flask
micro-service.

## 2. Languages

The header language selector really re-renders the site:

* **UI strings** come from `src/lib/i18n.ts` (English, हिन्दी, ଓଡ଼ିଆ dictionaries).
* **Content** (machine / material / offer / FAQ / festival text) is stored per language inside a
  `t` JSONB column and picked with `pick(t, lang, field)`, always falling back to English.
* The choice is persisted in `localStorage` + a cookie, and is recorded in analytics.

## 4. Festival engine

`src/lib/queries.ts → getActiveFestival()` runs in automatic mode: it finds the next enabled
festival whose date falls inside its own `daysBefore` window (default 5 days) and switches the
promo bar, colours, greeting, coupon and offer links site-wide. Turn automatic mode off in
Settings → Festival Mode to pin a festival manually and upload a custom banner/background.
Seeded festivals: New Year, Maha Shivaratri, Holi, **Raja**, **Rath Yatra**, Independence Day,
Ganesh Chaturthi, **Nuakhai**, Durga Puja, Dasahara/Dussehra, Diwali, Christmas.

## 5. WhatsApp integration

## 6. Image storage (important for deployment)

Uploads are written by `src/lib/upload.ts`:

1. **Cloudinary (recommended for Render / Vercel / any ephemeral disk)** — if
   `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY` and `CLOUDINARY_API_SECRET` are set, every file
   is pushed to Cloudinary (signed upload) and the returned `secure_url` is stored in PostgreSQL.
2. **Durable local storage fallback** — otherwise files are written to `UPLOAD_DIR`
   (default `.data/uploads`, outside `public/`) and served through the
   `GET /api/file/[name]` route. The URL saved in the database always resolves, survives restarts
   and redeployments on persistent volumes, and images fall back to a branded gradient card if a
   file is ever missing.

Attach a persistent disk (or set the Cloudinary variables) before deploying to a platform that
wipes its filesystem.

## 8. Running it

```bash
npm install
npx drizzle-kit push        # create / update the schema
npm run dev                 # http://localhost:3000
```

Production:

```bash
npm run build && npm start
```

The database is seeded automatically on first server start (`src/instrumentation.ts` →
`src/lib/seed.ts`): 3 staff users, 4 machines with full trilingual content, models, colours and
specifications, 6 raw materials, 10 spare parts, 4 offers, 12 festivals, 12 gallery photos,
9 FAQs, 46 enquiries, 9 tickets with timelines, subscribers and 90 days of analytics events.
You can also trigger it manually:

```bash
curl -X POST "http://localhost:3000/api/seed?secret=milan-seed-2026"
```

## 9. ROI calculator

The calculator is validated **twice**: instantly in the browser (`src/lib/roi.ts`) and again on
the server (`POST /api/roi`), so a tampered client cannot produce fake numbers. It returns
monthly production, revenue, material cost, gross and net monthly profit, annual profit,
payback period (months and days), first-year profit, ROI % and margin %.
`scripts/roi_engine.py` contains the identical logic in Python:

```bash
python3 scripts/roi_engine.py --pph 3500 --hours 8 --days 26 --sell 1.1 --raw 0.75 --machine 98000
python3 scripts/roi_engine.py --serve --port 8000   # optional Flask micro-service
```
